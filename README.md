# codex-global-memory

[OpenAI Codex](https://github.com/openai/codex) のグローバルメモリ（`~/.codex/AGENTS.md`）の公開版です。作者が使っている約3万バイトのメモリを、他の人にも役立つ判断を中心に約5,000バイトへ縮めました。依頼の目的・範囲・許可を保つこと、途中で止まらず実際に操作して確かめること、誤りを認めたらその場で原因を直すことを書いています。作者の環境だけで使う規則（委任先のモデル、個別のサービスなど）は外しています。

関連: スキル集 https://github.com/z0lw/codex-skills 、フック集 https://github.com/z0lw/codex-consent-hooks

## Codex に導入を頼む場合

下の文をコピーして Codex に貼り付けてください。Codex があなたの使い方を聞き、このメモリから合う規則を選んで、あなた向けに整えた案を出します。

```text
https://github.com/z0lw/codex-global-memory のグローバルメモリから、私の使い方に合う部分を選んで導入してください。
```

貼り付ける前に、Codex の権限を「フルアクセス」にしてください。導入先の `~/.codex` は、最初の権限では Codex が書き換えられません。設定の手順は https://note.z0lw.com/z0lw/a49b5b4a-7502-4c80-b22c-c85fe5e15f73 の手順3にあります。

## 導入手順（Codex 向け）

1. 最初に利用者へ「このメモリは、あなたの使い方に合う部分を選んで導入しますね」と伝える。作業の前に、入力欄の下の権限が「フルアクセス」になっているかを確かめ、違えば上の手順を案内する。
2. 利用者の `~/.codex/AGENTS.md` があれば読み、Codex を何に使っているか、何に困っているかを短く聞く。ファイルを読めば分かることは、聞かずに調べる。
3. `AGENTS.md` から利用者に効く規則を選び、利用者の使い方と言葉に合わせた案を示す。利用者が全文をそのまま使いたいと言えば、全文でもよい。
4. 利用者が了承したら、既存の指示を残したまま `~/.codex/AGENTS.md` に書く。重なる規則は、利用者の既存の指示を優先する。
5. 最終節「本人指定の必須要件」は、利用者が特に必須と決めた要件の置き場所。中身を残すか、利用者の要件に入れ替えるかを確かめる。
6. 任意: `~/.codex` を Git で管理している場合は、`.githooks/pre-commit` を `~/.codex/.githooks/` に置いて `chmod +x` し、`git -C ~/.codex config core.hooksPath .githooks` を設定する。このフックは、コミット時に変更された `AGENTS.md` を自動でステージし、最終節を除く本文が 30,000 バイト以内かを検査する。検査には同じ作者のスキル集の `edit-global-memory`（`~/.codex/skills/edit-global-memory/scripts/check_memory_size.py`）を使うので、先にそのスキルを入れる。入っていなければ、フックは検査を飛ばして案内だけを出す。
7. 終わったら、何をどこに書いたか、何を見送ったかを短く報告する。
